# Metal and Stars: Legacy Routes

Restore the three original direct space connections removed when Metal and Stars introduced its gate network. Original route names, endpoints, lengths and asteroid distributions match version 0.0.8. The current gate network remains available.

Requires Factorio 2.1.24, Space Age and the updated Metal and Stars fork. Native checks verified the three restored routes alongside the current subplanets. Use this addon for factories that need the earlier direct routes.
